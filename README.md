📌 Overview
This project demonstrates how to read a PDF file in Google Colab, extract its text, remove unnecessary spaces, count characters, and divide large text into smaller groups.
🛠️ Technologies Used
Python
Google Colab
PyPDF
Regular Expressions (re)
📋 Steps Performed
1. Read PDF
The program uploads and reads a PDF file using the pypdf library.
2. Extract Text
The text from all PDF pages is extracted and displayed.
3. Count Characters
The program calculates the total number of characters in the extracted text.
4. Remove Unnecessary Spaces
Extra spaces, new lines, and other unnecessary whitespace are removed from the text.
5. Count Characters After Cleaning
The number of characters in the cleaned text is displayed.
6. Divide Text into Groups
If the text contains around 2000 or more characters, it is divided into smaller groups of 2000 characters.
